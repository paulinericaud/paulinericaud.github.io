Game Jam

Global Game Jam 2026

The theme for the Global Game Jam's 2026 edition : Mask

We decided to create a little game where the player want to break into a museum to steal jewels, concealing their identity with a mask. They have to break the glass containing the jewel thanks to a point-and-click mini-game, then desactivate the cameras in the security room before leaving the building.

Code Game Jam 2026

The theme for the Global Game Jam's 2026 edition : Fête des clics !

The theme giving us a little space for inspiration, we decided to set our game in the context of a party, where one of the game available, the one we coded, was to put a nail in a log. The player has to click only when the cursor is at the right place, then click enough times so the nail goes into the log.
